# Prepare data from a `databook` for uploading to database

Prepares the data contained in a `databook` object for upload and writes
it to the database. This includes adding the source ETL script
`script_id` and, when applicable, resolving `source_id` values to
`participant_id` values and `event_id` using the `id_mapping` table.

## Usage

``` r
databasePrepareData(databook, script_id, con = NULL)
```

## Arguments

- databook:

  A list as generated by
  [`sourceScript()`](https://koenastam.github.io/beFAIR/reference/sourceScript.md).
  Must contain at least:

  - `$data`: A data frame with the table to upload.

  - `$codebook_name`: Character; target table name in the database.

  - `$codebook_version`: Character; version identifier for the codebook.

- script_id:

  Character. Both the identifier and file path of the ETL script; read
  to compute the MD5 hash.

- con:

  A DBI connection. If `NULL`, the default connection set by
  [`FAIRgroundConnect()`](https://koenastam.github.io/beFAIR/reference/FAIRgroundConnect.md)
  is used.

## Value

`TRUE` if data was successfully pushed and `table_script` updated,
`FALSE` otherwise.

## Details

Special handling is applied depending on `databook$codebook_name`:

- `"id_mapping"`: Adds a deterministic `participant_id` column via
  [`.addParticipantIds()`](https://koenastam.github.io/beFAIR/reference/dot-addParticipantIds.md).

- Other tables: If the data contains a `source_id` column, the function
  joins against the database `id_mapping` table to add `participant_id`.
  The `source_id` column is then set to `NA`.

- Other tables without `source_id`: if `participant_id` is already
  present in the data it is used directly; this is logged at `info`
  level.

If the data is successfully uploaded to the database, `table_script` is
also updated with metadata for that `script_id`, including the MD5 hash
of the ETL script and the codebook version.

## Examples

``` r
if (FALSE) { # \dontrun{
FAIRgroundConnect("LUCID_FAIRPOINT_TEST")
script_id <- "studies/LaCHMI/scripts/participant.R"
databook <- sourceScript(script_id = script_id)
databasePrepareData(databook, script_id = script_id)
} # }
```
