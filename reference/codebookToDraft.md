# Generate R code for initializing codebook entries

Reads the specified codebook and prints one assignment line per variable
to the console in the format `databook$data$<variable> <- <NA_type>`.
Fields that are auto-generated by the database (`script_id`,
`participant_id`, `event_id`) are skipped.

## Usage

``` r
codebookToDraft(codebook_name)
```

## Arguments

- codebook_name:

  Character. The name of the codebook (without `.yaml` extension).

## Value

Invisibly returns `NULL`. Output is written to the console via
[`cat()`](https://rdrr.io/r/base/cat.html).

## See also

[`codebookRead()`](https://koenastam.github.io/beFAIR/reference/codebookRead.md),
[`codebookToSummary()`](https://koenastam.github.io/beFAIR/reference/codebookToSummary.md)

## Examples

``` r
if (FALSE) { # \dontrun{
  codebookToDraft("participant")
} # }
```
