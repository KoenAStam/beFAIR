# Draft an ETL script for a study, experiment, or analysis

Creates a template R script under the appropriate `scripts/` subfolder.
The DATA section is generated by
[`codebookToDraft()`](https://koenastam.github.io/beFAIR/reference/codebookToDraft.md)
from the variables defined in the named codebook.

## Usage

``` r
draftScript(name, pillar, codebook_name, overwrite = FALSE)
```

## Arguments

- name:

  A character string specifying the name of the study, experiment, or
  analysis.

- pillar:

  A character string; one of `"studies"`, `"experiments"`, or
  `"analyses"`.

- codebook_name:

  A character string specifying the codebook name.

- overwrite:

  Logical. If `TRUE`, an existing script will be overwritten. Defaults
  to `FALSE`.

## Value

Called for its side effects. Writes an R script and invisibly returns
`NULL`.

## See also

[`codebookToDraft()`](https://koenastam.github.io/beFAIR/reference/codebookToDraft.md),
[`codebookToSummary()`](https://koenastam.github.io/beFAIR/reference/codebookToSummary.md)

## Examples

``` r
if (FALSE) { # \dontrun{
draftScript("CoHSI1", "studies", "participant")
draftScript("NIH_CyTOF_exvivo", "analyses", "som_measurement")
} # }
```
